## Suggested Project Catalog offers

Do not publish prices or delivery dates until you have estimated the actual workload. Use Basic, Standard, and Advanced tiers only when the difference in scope is clear.

1. **I will build a responsive React landing page for your business**
   - Define the number of sections and revision rounds
   - State whether copy, design, hosting, and domain setup are included
   - Add-ons can cover extra pages or deployment support

2. **I will fix responsive layout and UI issues on your website**
   - Ask for the website URL, issue list, source access, and target devices
   - Limit each tier by the number or complexity of fixes

3. **I will build a React dashboard or internal business interface**
   - Define screens, roles, forms, data source, and authentication needs
   - Separate UI-only work from backend and database integration

4. **I will develop a Flutter mobile app prototype**
   - Define screens, supported platform, data source, and build deliverables
   - Keep store publishing outside the base package unless explicitly included

## Before submitting each proposal

- Apply only when the core requirement matches your actual skills.
- Mention one specific detail from the job post in the opening lines.
- Share the single most relevant case study, not every project.
- Ask one useful question that shows you understood the work.
- Keep communication and payment on Upwork before a contract begins.
- Never promise a deadline until access, scope, and dependencies are clear.
- Do not claim technologies, results, or responsibilities you cannot verify.
